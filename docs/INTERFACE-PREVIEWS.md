# ZGTA 5 interface previews

[Downloads and guides](../README.md) · [Browser](#browser--mac-launcher) · [iOS](#ios-app)

## Browser / Mac launcher

These screenshots show the public Build 107 browser layout, captured in Chrome
on macOS on 31 October 2026. The Mac app opens the same interface. Other browser
platforms share this layout; these pictures do not establish testing on Windows,
Linux or Android. The selected resolution and FPS are example settings, not
performance results.

### Story mode

Choose Story mode or Free Roam from the menu, then adjust the launch setup.
The main navigation also leads to multiplayer, mods, graphics, controls, saves
and support.

![Browser Story mode with launch setup and main navigation](images/browser/Story-mode-107.jpg)

### Graphics

Graphics presets provide a starting point. Resolution and frame rate have
separate controls on the same page.

![Browser Graphics page with preset cards and display controls](images/browser/Graphics-107.jpg)

### Controls

Keyboard, mouse, controller and targeting options stay inside the launcher's
main navigation.

![Browser Controls page with mouse and controller settings](images/browser/Controls-107.jpg)

### Mods

The Mod Manager is an integrated launcher page. This preview shows its upper
section; the vehicle catalog and other play tools continue below. Spawning
becomes available after the game world loads, and vehicles need matching assets.

![Browser Mod Manager integrated into the main navigation](images/browser/Mods-107.jpg)

## iOS app

These are fresh iOS 26.3 Simulator captures on the iPhone 15 Pro profile, using
HomeView, SettingsViewController and their supporting UIKit sources from public
Build 107. The same screens were also checked on the smaller iPhone SE 2020
profile. This screen-only harness starts no game engine; file readiness and
hardware values are fixtures. These images show the native layout, not measured
phone performance.
