# ZGTA 5 — 1.2

Published after owner-confirmed Intel Mac installation, design/navigation and
game startup with existing data, and the final **Yes — publish 1.2**.

- Refreshed browser design with the iOS-style black and green surfaces and
  monochrome Los Santos map; the colored city artwork is removed.
- Existing desktop layout, navigation and button positions are retained.
  Mods, Graphics, Controls, Saves and Support stay integrated into the page.
- Mac launcher branding and product version now show ZGTA 5 / 1.2. Internal
  build numbers remain separate from the product version.
- Matching Mac DMG and browser/Mac/Linux, Windows and Android downloads include
  the new interface. Existing game folders, launcher address, saves, mods,
  character data and private LAN/Tailscale hosting are preserved.

This is a browser/Mac update. The iOS app remains the unchanged owner-tested
Build 109 / 1.1 beta 1; there is no replacement IPA or Sileo installer in 1.2.
The gameplay renderer, voice implementation and memory policy are unchanged.
No new FPS, thermal or 3 GB device performance improvement is claimed.

The Mac app remains ad-hoc signed and not notarized. Apple Silicon, Windows,
Linux and Android execution are untested. Android remains the experimental
Termux/browser package, not an APK. Your own matching game files are required.
