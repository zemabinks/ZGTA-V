# Preview image provenance

The current screenshots used by the repository README and interface gallery are
in `browser/` (real Chrome captures of Build 107) and `ios/` (real iOS Simulator
captures of the production Build 107 UIKit views).

`Home-final.png`, `With-friends-final.png`, `Settings-final.png` and
`Favorites-offline.png` are retained historical layout assets. Their platform
provenance was not verified, so they are not presented as current iOS screenshots.
