Modern GTA map icon reference samples

Source: https://docs.fivem.net/docs/game-references/blips/
Images: https://docs-backend.fivem.net/blips/
Retrieved: 21 October 2026

The catalog records the exact official reference IDs, names, source URLs,
byte sizes and SHA-256 digests. The artwork depicts Grand Theft Auto V / GTA
Online symbols; original game artwork belongs to its respective owners.
This project does not claim original authorship or a new license for it.

Only 22 symbols absent from the supplied older minimap, including the three
related unavailable-heist variants, are included. No FiveM executable, script
runtime, account, network service or full game archive is required.

The build generator converts the verified 32x32 RGBA pixels to stock SWF
DefineShape3 row runs. Original alpha values and pixel colours are retained.
The generated modern-map-icons.json is a hash-checked delta applied to a
temporary copy of the original minimap archive. Original files remain intact.
